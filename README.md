# 🛒 Парсер объявлений Avito (ноутбуки)

Асинхронный веб-парсер на Python для сбора информации о ноутбуках с сайта Avito.  
Проект демонстрирует навыки работы с динамическими страницами, обхода антибот-защиты, пагинации и структурирования данных.

---

## 📌 Возможности

- Сбор данных со страницы поиска:  
  - Название объявления  
  - Цена
  - Дата публикации  
  - Ссылка на объявление  
  - ID объявления
- Пагинация – автоматический переход по всем доступным страницам  
- Обработка капчи с ручным подтверждением (возможность пропуска)  
- Асинхронная загрузка страниц (высокая скорость)  
- Сохранение результатов в формате JSON  

---

## 🛠 Технологии

- **Python 3.10+**  
- **Playwright** – управление браузером (динамический контент)  
- **asyncio** – асинхронный ввод/вывод  
- **JSON** – хранение результатов

## 🚀 Установка и запуск

1. **Клонируйте репозиторий**

```bash
git clone https://github.com/anantaaya/avito-parser.git
cd avito-parser
```

2. **Создайте виртуальное окружение (рекомендуется)**

```bash
python -m venv venv
source venv/bin/activate      # для Linux/Mac
venv\Scripts\activate         # для Windows
```

3. **Установите зависимости**

```bash
pip install -r requirements.txt
playwright install
```

4. **Запустите парсер**

```bash
python avito_parser.py
```

> При первом запуске вручную решите капчу, если она появится. В дальнейшем скрипт будет ожидать ввода `Enter` после решения.

## ⚙️ Конфигурация

Все основные настройки вынесены в файл `config.py`:
- `BASE_URL` – ссылка на страницу поиска
- `MAX_PAGES` – максимальное число страниц (None = все)
- `HEADLESS` – режим браузера (True/False)
- `USER_AGENT`, `VIEWPORT`, `TIMEOUT`, `OUTPUT_FILE` и другие параметры.
